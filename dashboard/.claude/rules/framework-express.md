# Express 하네스 (framework/express)

버전과 무관하게 항상 적용되는 규칙. 비동기 에러 전파는 4와 5의 동작이 정반대라 버전 하네스로
내렸다 — 여기 두면 한쪽에는 틀린 규칙이 된다.

## 핵심 규칙

1. **에러 처리 미들웨어는 인자 4개(`err, req, res, next`)를 명시하고 모든 라우트 뒤 맨 마지막에 둔다.** 인자가 3개면 Express가 일반 미들웨어로 취급해 에러를 못 받고, 순서가 앞이면 등록돼 있어도 호출되지 않는다 — 둘 다 에러 없이 조용히 동작하지 않는 형태다.
2. **라우트는 등록 순서대로 먼저 매칭되는 것이 이긴다.** `/users/:id`를 `/users/new`보다 먼저 등록하면 `new`가 `id` 값으로 잡힌다. 구체적인 경로를 파라미터 경로보다 먼저 등록한다.
