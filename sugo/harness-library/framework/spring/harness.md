# Spring Boot 하네스 (framework/spring)

## 핵심 규칙

1. **생성자 주입만 사용한다.** `@Autowired` 필드 주입 금지. 의존성을 생성자로 받아야 그 클래스를 mock 없이 단위 테스트할 수 있다 — 필드 주입은 테스트가 컨테이너 없이는 객체를 만들 수 없게 만든다.
2. **JPA 엔티티를 API 응답으로 직접 노출하지 않는다.** DTO로 변환해서 내보낸다 — 엔티티를 그대로 노출하면 지연 로딩 필드 직렬화 시 예외가 나거나, 스키마 변경이 곧바로 API 계약 변경이 된다.
3. **배선(설정·빈 등록)을 바꾸면 `@SpringBootTest` 컨텍스트 로드 테스트로 확인한다(mock 없이).** 단위 테스트가 다 통과해도 스프링 컨텍스트 자체가 안 뜨는 경우를 잡아내는 건 이것뿐이다.
