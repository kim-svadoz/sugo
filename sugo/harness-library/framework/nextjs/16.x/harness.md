# Next.js 16 하네스 (framework/nextjs/16.x)

`framework/nextjs` + `15.x` 규칙 위에, 16(현행 16.3.x)에서 제거·개명된 것들이다. 15에서 경고로만
넘어가던 것들이 16에서는 동작하지 않는다.

## 핵심 규칙

1. **동기 요청 API 접근은 이제 동작하지 않는다.** `cookies()`/`headers()`/`params`/`searchParams`의 동기 접근이 완전히 제거됐다 — 15에서 경고를 무시하고 남겨둔 코드가 16에서 런타임에 터진다.
2. **`middleware.ts`를 새로 만들지 않는다.** 16에서 `proxy.ts`로 이름이 바뀌었고 export하는 함수명도 `proxy`다. 예전 이름으로 파일을 만들면 **아무 에러 없이 그냥 실행되지 않는다** — 인증 미들웨어라면 보호 장치가 통째로 빠진 채 배포된다.
3. **`proxy.ts`는 Node.js 런타임 전용이라는 전제로 쓴다.** Edge 런타임 가정으로 짠 코드를 그대로 옮기지 않는다.
4. **Turbopack이 기본 번들러라는 전제로 설정한다.** 커스텀 webpack 설정에 의존하는 코드는 16에서 그대로 적용되지 않는다 — 빌드는 통과하는데 의도한 변환만 빠지는 형태로 드러난다.
