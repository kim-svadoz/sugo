# Express 하네스 (framework/express)

## 핵심 규칙

1. **에러 처리 미들웨어를 마지막에 등록.** 모든 라우트 뒤에 4-arity 에러 핸들러를 둔다.
2. **async 라우트 핸들러의 예외를 반드시 next(err)로 전달.** try/catch 없이 던지면 프로세스가 죽을 수 있다.
3. **라우터를 도메인별로 분리.** 하나의 파일에 모든 라우트를 몰아넣지 않는다.
4. **입력 검증 미들웨어를 라우트 핸들러 앞단에.** 컨트롤러 내부에서 원시 req.body를 신뢰하지 않는다.
5. **민감 헤더/쿠키는 명시적으로 설정.** helmet 등으로 기본 보안 헤더 적용.

## 체크리스트

- [ ] 새 async 라우트 핸들러가 에러를 next()로 넘기는지 확인
- [ ] 에러 핸들러 미들웨어가 라우트 등록 이후에 있는지 확인
