# Node.js 24 하네스 (framework/node/24.x)

현행 활성 LTS(2025-10 진입, 2028-04까지). `framework/node` + `22.x` 규칙 위에.

## 핵심 규칙

1. **통합 테스트의 공유 자원은 전역 setup/teardown API로 관리한다.** 24에서 내장 러너에 전용 API가 생겼다 — DB 커넥션이나 테스트 서버를 각 테스트 파일에서 개별로 띄우면 포트 충돌과 정리 누락이 난다.
2. **서브테스트 자동 대기에 기대되, 명시적 `await`를 지우지는 않는다.** 24는 자동으로 기다리지만, 그 코드가 22 이하에서 돌면 다시 거짓 그린이 된다. 라이브러리처럼 여러 런타임에서 도는 코드라면 명시적 `await`를 유지한다.
3. **`URLPattern`·`RegExp.escape`를 쓸 때 대상 런타임을 확인한다.** 24 전역이라 브라우저나 하위 Node에서 같은 코드가 안 돈다.
4. **npm 11이 기본이므로 lockfile 재생성 시 다른 개발자 환경을 확인한다.** 하위 npm에서 생성한 lockfile과 섞이면 설치 결과가 갈린다.
