# Node.js 22 하네스 (framework/node/22.x)

`framework/node` 공통 규칙에 더해. 22는 유지보수 LTS(2027-04까지)다.

## 핵심 규칙

1. **테스트 러너는 내장(`node --test`)을 기본으로 검토한다.** 22에서 안정화됐다 — 외부 러너를 새로 들일 때는 내장으로 안 되는 이유가 있어야 한다.
2. **`node --test`의 서브테스트는 명시적으로 `await`한다.** 자동 대기는 24부터다. 22에서 빠뜨리면 실패가 통과로 보고된다.
3. **`.env` 로딩에 dotenv를 새로 추가하지 않는다.** `node --env-file`이 내장이다.
4. **CommonJS에서 ESM 패키지를 쓸 때 동적 `import()` 우회를 새로 만들지 않는다.** 22부터 `require(esm)`이 되므로, 우회 코드는 그대로 남아 부채가 된다.
