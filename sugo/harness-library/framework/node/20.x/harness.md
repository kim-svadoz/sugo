# Node.js 20 하네스 (framework/node/20.x)

`framework/node` 공통 규칙에 더해. 20은 지원이 끝난 계열이라 아래는 "버티는 법"이지 권장 스택이
아니다.

## 핵심 규칙

1. **`node --test`(내장 테스트 러너)의 서브테스트를 반드시 `await`한다.** 20의 러너는 서브테스트 완료를 자동으로 기다리지 않는다 — 안 기다리면 **실패한 테스트가 통과로 보고된다.** 거짓 그린이 나오는 대표 지점이다.
2. **`fetch`/`FormData`/`WebSocket` 폴리필을 새로 추가하지 않는다.** 18부터 표준 내장이다.
3. **런타임 상향 계획을 코드로 막지 않는다.** 20 전용 API나 폐기된 호출에 새로 의존하면 22/24 이관 때 다시 써야 한다.
