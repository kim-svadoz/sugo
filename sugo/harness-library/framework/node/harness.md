# Node.js 하네스 (framework/node)

## 핵심 규칙

1. **비동기는 async/await로 통일.** 콜백 스타일 API를 새로 만들지 않는다.
2. **환경변수는 시작 시점에 검증.** 필수 env가 없으면 부팅 초기에 명확한 에러로 즉시 실패(fail-fast).
3. **미처리 예외/거부를 로깅.** `process.on('unhandledRejection'/'uncaughtException')`으로 최소한 로그는 남긴다.
4. **의존성 최소화.** 표준 라이브러리로 되는 일에 패키지를 추가하지 않는다.
5. **입력 검증은 경계에서.** 라우트 핸들러 진입점에서 스키마 검증(zod 등) 후 내부 로직은 신뢰.
6. **graceful shutdown.** SIGTERM/SIGINT를 받으면 진행 중인 요청을 마치고 종료.

## 체크리스트

- [ ] 새 환경변수를 추가했다면 시작 시 검증 코드도 추가했는지 확인
- [ ] 외부 입력을 받는 지점에 스키마 검증이 있는지 확인
