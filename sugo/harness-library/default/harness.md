# 기본 하네스 (default)

모든 프로젝트에 언어/프레임워크와 무관하게 항상 적용되는 최소 공통 규칙. 다른 특화 하네스가
감지되지 않았거나 요청한 하네스 id를 찾지 못했을 때 폴백으로도 사용된다.

## 핵심 규칙

1. **에러를 삼키지 않는다.** catch/except에서 로그도 재전파도 없이 무시하지 않는다. 의도적으로 무시할 땐 그 자리에 이유를 남긴다.
2. **일어날 수 없는 상황에 대한 방어 코드를 넣지 않는다.** 내부 호출 경계는 이미 검증된 것으로 신뢰하고, 검증은 시스템 경계(외부 입력)에서만 한다. 일어날 수 없는 케이스를 방어하는 코드는 읽는 사람에게 "이게 실제로 일어날 수 있다"는 잘못된 신호를 준다.
3. **비밀정보를 하드코딩하지 않는다.** API 키·토큰·비밀번호는 코드에도, 커밋 메시지에도 남기지 않는다.
4. **요청받은 범위 밖 파일을 건드리지 않는다.** 관련 있어 보여도 지시받지 않은 리팩토링·정리는 별도로 확인받는다.
5. **동작을 증명하지 않고 완료라고 보고하지 않는다.** 테스트나 실제 실행으로 확인하기 전에는 "됐다"고 말하지 않는다.
