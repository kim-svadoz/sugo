# Poetry 1.x 하네스 (buildtool/poetry/1.x)

`buildtool/poetry` 공통 규칙에 더해. 2로 올라갈 때 깨지는 지점을 미리 피하는 것이 핵심이다.

## 핵심 규칙

1. **`poetry export`를 빌드 파이프라인의 필수 단계로 만들지 않는다.** 2에서 코어에서 빠져 플러그인이 됐다 — 의존하면 업그레이드 순간 CI가 멈춘다.
2. **`[tool.poetry]`에만 메타데이터를 두더라도 PEP 621 이관을 염두에 둔다.** 2는 표준 `[project]` 테이블을 지원한다 — 이름·버전·의존성을 표준 위치로 옮길 수 있게 커스텀 스크립트가 `[tool.poetry]` 구조를 파싱하지 않게 한다.
3. **`poetry install --sync`로 환경을 정리한다.** 그냥 install은 제거된 의존성을 남겨서, 로컬에서만 되는 상태를 만든다.
