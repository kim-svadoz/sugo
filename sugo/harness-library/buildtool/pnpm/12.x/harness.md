# pnpm 12 하네스 (buildtool/pnpm/12.x)

현행 계열(2026-08). `buildtool/pnpm` + `10.x` 규칙 위에. 12는 구현이 Rust로 재작성된 버전이라,
**성능 특성과 에러 메시지가 달라지고 내부 동작에 기대던 코드가 깨진다.**

## 핵심 규칙

1. **pnpm의 출력 형식을 파싱하는 스크립트를 만들지 않는다.** 재작성으로 로그·에러 메시지 형식이 바뀐다. CI 스크립트가 출력 문자열에 의존하면 조용히 오탐/미탐이 된다 — 종료 코드와 `--json` 출력을 쓴다.
2. **팀과 CI의 pnpm 버전을 `packageManager` 필드로 고정한다.** 10과 12가 섞이면 lockfile 처리와 설치 결과가 갈린다. corepack이 이 필드를 보고 버전을 맞춘다.
3. **`node_modules` 내부 구조에 기대는 경로 하드코딩을 하지 않는다.** 심링크 레이아웃은 구현 세부사항이다 — 모듈 해석은 런타임에 맡긴다.
4. **10의 스크립트 차단 정책은 그대로 유효하다.** 재작성됐다고 `onlyBuiltDependencies` 관리가 없어지지 않는다.
