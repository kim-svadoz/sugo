# Gradle 8 하네스 (buildtool/gradle/8.x)

`buildtool/gradle` 공통 규칙에 더해. 8은 9로 가는 길을 막지 않는 것이 핵심이다.

## 핵심 규칙

1. **빌드 스크립트에서 다른 태스크의 출력을 직접 참조하지 않는다.** 태스크 간 의존을 `dependsOn`과 출력 프로퍼티로 선언한다 — 암묵적 참조는 9의 설정 캐시에서 그대로 실패한다.
2. **폐기 경고를 무시하지 않는다.** `--warning-mode all`로 확인한다. 8의 폐기 경고는 9에서 제거된 API를 가리키므로, 남겨두면 업그레이드가 한꺼번에 터진다.
3. **Groovy DSL 신규 작성보다 Kotlin DSL(`.kts`)을 검토한다.** 타입 안전과 자동완성이 되고, 빌드 로직 오류가 실행 시점이 아니라 컴파일 시점에 드러난다.
