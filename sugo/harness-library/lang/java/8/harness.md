# Java 8 하네스 (lang/java/8)

`lang/java` 공통 규칙에 더해, **Java 8에 묶여 있는 코드**에만 적용되는 제약이다. Java 8은
2014년 문법이고 공개 업데이트가 끝난 지 오래다 — 아래는 "이 버전에서 할 수 있는 최선"이지
권장 스택이 아니다.

## 핵심 규칙

1. **`var`, `record`, `sealed`, 텍스트 블록, `switch` 표현식을 쓰지 않는다.** 전부 Java 9 이후 문법이라 컴파일 자체가 안 된다. 생성 코드에 섞여 들어가면 빌드가 깨진다.
2. **`Optional`을 필드나 파라미터 타입으로 쓰지 않는다.** Java 8의 `Optional`은 반환값 전용으로 설계됐고 직렬화도 안 된다. 필드에 쓰면 프레임워크 직렬화 지점에서 깨진다.
3. **스트림을 재사용하지 않는다.** 한 번 소비한 `Stream`을 다시 쓰면 `IllegalStateException`이다. 재사용이 필요하면 컬렉션으로 받아둔다.
4. **`new Date()`/`SimpleDateFormat`을 새로 쓰지 않는다.** `SimpleDateFormat`은 스레드 안전하지 않아 동시 요청에서 날짜가 섞인다 — Java 8에도 이미 `java.time`이 있다.
