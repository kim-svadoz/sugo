# Java 25 하네스 (lang/java/25)

현재 최신 LTS(2025-09). `lang/java` + 17 + 21 규칙 위에 25에서 확정된 것들을 더한다. 26 같은
비-LTS 상위 버전도 이 하네스로 매핑된다.

## 핵심 규칙

1. **가상 스레드에 컨텍스트를 넘길 때 `ThreadLocal` 대신 `ScopedValue`를 쓴다.** Java 25에서 정식 기능이 됐다. `ThreadLocal`은 가상 스레드가 수백만 개일 때 메모리를 그만큼 잡고, 정리를 빠뜨리면 그대로 누수가 된다. `ScopedValue`는 바인딩 범위를 벗어나면 자동으로 사라지고 불변이라 덮어쓰기 사고가 없다.
2. **생성자에서 `super()` 호출 전에 인자를 검증한다.** Java 25의 유연한 생성자 본문(flexible constructor bodies)으로 `super()` 앞에 검증 코드를 둘 수 있다. 상위 생성자가 불완전한 값으로 먼저 실행되는 문제를 없앤다.
3. **프로덕션 코드에 compact source file(클래스 선언 없는 파일)과 인스턴스 `main`을 쓰지 않는다.** 학습·프로토타입용으로 들어온 기능이다. 실제 애플리케이션 코드에 섞이면 패키지 구조와 접근 제어가 흐트러진다.
4. **`import module`(모듈 임포트 선언)로 패키지 임포트를 뭉뚱그리지 않는다.** 한 줄로 모듈 전체가 들어오면 어떤 타입이 어디서 왔는지 사라지고, 서로 다른 모듈의 동명 타입이 충돌한다.
