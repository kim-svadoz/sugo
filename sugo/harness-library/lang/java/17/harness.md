# Java 17 하네스 (lang/java/17)

`lang/java` 공통 규칙에 더해, Java 17(LTS)에서 기본값이 되어야 하는 것들이다. Spring Boot 3/4의
최소 요구 버전이기도 하다.

## 핵심 규칙

1. **불변 데이터 홀더는 `record`로 만든다.** DTO·값 객체를 `record`로 선언하면 `equals`/`hashCode`/`toString`이 자동으로 쌍을 맞춰 생성된다 — 공통 규칙의 "equals/hashCode 쌍" 사고가 구조적으로 불가능해진다.
2. **타입 계층을 닫아야 하면 `sealed`로 선언한다.** 허용 구현을 컴파일러가 강제하고, `switch`에서 모든 경우를 다뤘는지 컴파일 시점에 검증된다 — 새 하위 타입이 생겼을 때 처리 누락이 런타임이 아니라 빌드에서 터진다.
3. **`instanceof` 뒤에 바로 캐스팅하지 않는다.** `if (o instanceof User u)` 패턴으로 받는다. 검사와 캐스팅이 분리되면 나중에 한쪽만 바뀌어 `ClassCastException`이 난다.
4. **여러 줄 문자열(SQL·JSON)은 텍스트 블록(`"""`)으로 쓴다.** `+` 연결은 개행/공백 누락으로 조용히 깨진 쿼리를 만든다.
5. **`switch`는 표현식 형태로 쓰고 fall-through에 의존하지 않는다.** `->` 형태는 break 누락이 불가능하고, 값을 반환하므로 분기마다 대입을 빠뜨릴 수 없다.
