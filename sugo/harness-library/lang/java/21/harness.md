# Java 21 하네스 (lang/java/21)

`lang/java` + `lang/java/17` 규칙 위에, Java 21(LTS)에서 동시성 모델이 바뀐 부분이 핵심이다.

## 핵심 규칙

1. **블로킹 I/O 작업에 고정 크기 플랫폼 스레드 풀을 새로 만들지 않는다.** 가상 스레드(`Executors.newVirtualThreadPerTaskExecutor()`)를 쓴다. 요청당 스레드 모델이 다시 성립해서, 풀 크기 튜닝으로 처리량을 맞추던 작업 자체가 없어진다.
2. **가상 스레드 안에서 `synchronized` 블록으로 I/O를 감싸지 않는다.** Java 21의 가상 스레드는 `synchronized` 안에서 블로킹되면 캐리어 스레드에 **고정(pinning)**되어, 가상 스레드를 쓰는 의미가 사라지고 오히려 처리량이 떨어진다. `ReentrantLock`을 쓴다.
3. **가상 스레드를 풀링하지 않는다.** 가상 스레드는 생성 비용이 거의 없는 일회용이다. 풀에 담아 재사용하면 `ThreadLocal` 오염과 컨텍스트 누수를 다시 불러온다.
4. **`sealed` 계층 분기는 `switch` 패턴 매칭으로 처리한다.** 모든 하위 타입을 다뤘는지 컴파일러가 검사하므로 `default` 절로 뭉개지 않는다 — `default`를 두면 새 타입 추가 시 조용히 그리로 빠진다.
5. **리스트의 처음/끝 접근은 `getFirst()`/`getLast()`를 쓴다.** `list.get(list.size() - 1)` 관용구는 빈 리스트에서 `-1` 인덱스 예외로 터진다.
