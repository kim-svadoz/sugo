# TypeScript 하네스 (lang/typescript)

## 핵심 규칙

1. **`any` 금지.** 타입을 모르면 `unknown` + 타입가드로 좁힌다. 부득이하게 `any`가 필요하면
   한 줄 주석으로 이유를 남긴다.
2. **`tsconfig.json`에 `strict: true`.** strict 계열 개별 플래그를 끄지 않는다.
3. **암시적 `any` 반환 금지.** 함수 반환 타입은 추론이 명확하지 않으면 명시한다(공개 API는 항상 명시).
4. **널 단언(`!`) 남용 금지.** 널 가능성은 타입가드나 옵셔널 체이닝으로 다룬다. 불가피한 경우만 예외.
5. **`interface` vs `type`:** 객체 형태 확장 가능성이 있으면 `interface`, 유니온/매핑 타입은 `type`.
6. **열거값은 union literal type을 우선.** `enum`은 트리쉐이킹/직렬화 이슈가 있어 꼭 필요할 때만.
7. **비동기 함수는 반드시 에러 처리.** `async` 함수 호출부에서 `.catch` 누락 또는 미처리 rejection 금지.
