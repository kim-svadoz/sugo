# TypeScript 7.x 하네스 (lang/typescript/7.x)

현행 최신(7.0 GA 2026-07). 컴파일러와 언어 서비스가 **Go로 재작성**되어 타입체크가 8~12배 빨라진
버전이다. 문법은 대체로 그대로지만 **컴파일러를 확장해 쓰던 코드**가 성립하지 않는다.

## 핵심 규칙

1. **`typescript` 컴파일러 API를 프로그램적으로 호출하는 코드를 새로 만들지 않는다.** JS 구현에 붙어 있던 커스텀 트랜스포머·AST 조작은 네이티브 컴파일러에서 같은 형태로 동작하지 않는다. 코드 생성이 필요하면 컴파일러 확장이 아니라 별도 생성 단계로 분리한다.
2. **타입체크가 빨라졌다고 CI에서 타입체크를 생략하지 않는다.** 로컬이 빨라진 만큼 "어차피 에디터가 잡아준다"로 흘러가기 쉬운데, 에디터는 열려 있는 파일만 본다.
3. **`tsc`와 `tsgo` 결과가 다르면 그 차이를 덮지 않고 원인을 찾는다.** 이관 중 두 컴파일러가 다른 결론을 내는 지점은 대개 예전 구현이 관대하게 넘어가던 자리다 — 설정으로 맞추면 실제 타입 문제를 덮는다.
4. **성능이 좋아졌다고 `skipLibCheck`를 끄고 전부 검사하도록 바꿀 때는 CI 시간을 확인한다.** 의존성 타입 오류까지 빌드 실패로 바뀌면 우리 코드와 무관한 이유로 배포가 막힌다.
