# TypeScript 6.x 하네스 (lang/typescript/6.x)

`lang/typescript` + `5.x` 규칙 위에. 6.0(2026-03)은 **JS 기반 `tsc`의 마지막 메이저**이자 7.0
전환용 릴리스다 — 이 버전의 목적 자체가 "7.0에서 깨질 것을 지금 드러내는 것"이다.

## 핵심 규칙

1. **6.0이 내는 폐기 경고를 끄지 않는다.** 이 경고들은 7.0에서 그대로 에러가 된다. 경고를 억제하면 이관 시점에 한꺼번에 터지고, 그때는 어느 변경이 원인인지 추적할 수 없다.
2. **바뀐 기본값을 설정으로 되돌리지 않는다.** 6.0이 기본값을 바꾼 항목을 예전 값으로 고정하면 7.0 이관이 그만큼 밀린다 — 되돌릴 거라면 왜 되돌리는지, 언제 풀 것인지를 남긴다.
3. **`enum`/`namespace`는 이제 제거 대상이다.** 5.x에서는 "새로 쓰지 않기"였지만 6.x에서는 남아 있는 것을 걷어낼 시점이다.
4. **7.0 마이그레이션 플래그를 켜서 미리 검증한다.** 6.0이 제공하는 플래그로 지금 통과시켜 두면 7.0 전환이 버전 올리기만 남는다.
