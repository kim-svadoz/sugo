# Python 3.10 하네스 (lang/python/3.10)

`lang/python` 공통 규칙에 더해, 3.10~3.11에서 기본값이 되어야 하는 표기다.

## 핵심 규칙

1. **유니온은 `X | None`으로 쓴다.** `Optional[X]`/`Union[X, Y]`를 새로 쓰지 않는다 — 같은 파일 안에 두 표기가 섞이면 선택적 인자와 필수 인자의 구분이 눈에 안 들어온다.
2. **분기 대상이 값의 "구조"라면 `if/elif` 사슬 대신 `match`를 쓴다.** 구조 분해와 분기가 한 자리에 모여 조건과 꺼내기가 어긋날 여지가 없어진다.
3. **`match`에 `case _` 기본 절을 습관적으로 붙이지 않는다.** 모든 경우를 적어두면 새 형태가 들어왔을 때 조용히 기본 절로 빠지지 않고 드러난다.
4. **여러 컨텍스트 매니저는 괄호로 묶어 나눠 쓴다.** 백슬래시 줄바꿈은 뒤에 공백 하나만 붙어도 깨진다.
