# Python 3.14 하네스 (lang/python/3.14)

현재 최신 안정 계열(2025-10). `lang/python` + `3.10` + `3.12` 규칙 위에 3.14에서 달라진 것들이다.

## 핵심 규칙

1. **어노테이션이 지연 평가된다는 전제로 쓴다(PEP 649).** 어노테이션은 접근 시점에 평가되므로 `from __future__ import annotations`와 문자열 따옴표 회피가 더 이상 필요 없다. 대신 런타임에 어노테이션을 읽는 코드는 `typing.get_type_hints()`나 `annotationlib`로 명시적으로 가져온다 — `__annotations__`를 직접 읽던 코드가 기대와 다른 형태를 받는다.
2. **free-threaded 빌드를 대상으로 한다면 GIL이 없다는 전제로 공유 상태를 보호한다.** 3.14에서 실험 딱지를 뗐다(PEP 779). GIL이 암묵적으로 보장하던 원자성이 사라지므로, 기존 코드의 "이 정도는 안전하겠지" 가정이 그대로 경쟁 조건이 된다 — 공유 가변 상태에는 명시적 락을 건다.
3. **외부 입력으로 문자열을 조립할 땐 t-string(PEP 750)을 고려한다.** f-string은 즉시 문자열이 되어 값과 리터럴의 구분이 사라지지만, t-string은 구조를 유지한 채 넘겨 SQL·HTML 조립 지점에서 이스케이프를 강제할 수 있다.
4. **`asyncio.gather`를 새로 쓰지 않는다.** `TaskGroup`이 표준 경로다(3.12 규칙 유지).
