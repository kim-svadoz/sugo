# Python 하네스 (lang/python)

## 핵심 규칙

1. **가변 기본인자를 쓰지 않는다.** `def f(x, items=[])`는 그 리스트를 호출 간에 공유한다 — 파라미터 하나가 함수의 모든 호출에 걸쳐 상태를 몰래 유지하는 고전적 함정이다. 기본값은 `None`으로 두고 함수 안에서 초기화한다.
2. **맨몸 `except:`를 쓰지 않는다.** `SystemExit`/`KeyboardInterrupt`까지 삼켜서 프로세스를 죽일 수 없게 만든다. 최소 `except Exception:`, 가능하면 구체적인 예외 타입.
3. **파일/커넥션 등 해제가 필요한 자원은 `with`로 연다.** 명시적으로 닫지 않으면 예외 경로에서 해제가 누락된다.
