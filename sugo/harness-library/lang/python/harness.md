# Python 하네스 (lang/python)

## 핵심 규칙

1. **타입힌트를 기본으로.** 공개 함수/메서드 시그니처에 타입힌트를 붙인다(`mypy`/`pyright` 대상).
2. **가변 기본인자 금지.** `def f(x, items=[])` 금지 — `None` 기본값 + 함수 내부 초기화.
3. **예외는 구체적으로.** 맨몸 `except:` 금지, 최소 `except Exception:`, 가능하면 구체 타입.
4. **f-string 우선.** `%` 포맷팅/`.format()` 대신 f-string.
5. **컨텍스트 매니저로 자원 관리.** 파일/커넥션은 `with`로 연다.
6. **패키지 구조는 명시적 임포트.** `from x import *` 금지.

## 체크리스트

- [ ] 새 공개 함수에 타입힌트 있는지 확인
- [ ] 가변 기본인자 없는지 확인
- [ ] 맨몸 except가 없는지 확인
