# 게이트 철학 (GATE_PHILOSOPHY) — 절대 약화 금지

sugo의 DNA는 "속임수를 잡는다"이다. 게이트는 자기보고가 아닌 **실행 증거로만** 상태 전이를 허용한다.

## 4대 원칙
1. **게이트는 행동을 증명한다.** 통과=동작 증명. "테스트 그린"·"정적 통과"는 프록시일 뿐 증명이 아니다.
   우회는 오직 명시적 '미검증' 라벨로만.
2. **순서 강제.** 스킵 불가 — 상태머신 전제조건으로 서버가 차단한다(클라이언트 신뢰 안 함).
3. **자기보고 불신.** "통과했다" 주장과 실제 실행 증거를 서버가 분리·교차검증한다. 라벨-모순
   (그린 증거 있는데 환경부재 주장)은 차단된다.
4. **하위호환은 라벨로.** 새 게이트는 opt-in/조건부, 미충족은 차단이 아닌 라벨(교착 금지). 단,
   **라벨 남용은 완료 등급 강등으로 벌한다**(§4.6).

## 실전 규율
- 게이트가 막으면 라벨로 도망치지 말고 **실제로 충족**시켜라(테스트를 진짜 돌리고, 실배선 테스트를
  진짜 추가하고, 풀검증 명령으로 진짜 검증).
- 환경 부재(빌드환경 없음 등)는 정직한 탈출구지만, 같은 세션에 그린 증거가 있으면 모순으로 차단된다.
- "확인했다는데 결과 안 밝힘", "그린이라는데 증거 없음", "통과라는데 기록은 실패", "미검증이라는데
  그린 증거 있음" — 전부 안전측 기본값 = 차단.
