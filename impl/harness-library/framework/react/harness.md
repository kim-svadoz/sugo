# React 하네스 (framework/react)

## 핵심 규칙

1. **컴포넌트는 순수하게.** 렌더 중 side effect 금지 — `useEffect`/이벤트 핸들러 안에서만.
2. **`useEffect` 의존성 배열을 정확히.** 누락/과잉 의존성 금지(eslint-plugin-react-hooks 기준).
3. **key는 안정적인 값으로.** 배열 index를 key로 쓰지 않는다(순서가 바뀌는 리스트).
4. **상태 최소화.** 파생 가능한 값은 별도 state로 만들지 않고 렌더 중 계산.
5. **불필요한 리렌더 방지보다 먼저 올바름.** 최적화(memo 등)는 실제 성능 문제가 확인된 뒤에.
6. **접근성 기본.** 인터랙티브 요소에 적절한 시맨틱 태그/aria 속성.

## 체크리스트

- [ ] useEffect 의존성 배열이 실제 사용값과 일치하는지 확인
- [ ] 리스트 key로 index를 쓰지 않았는지 확인
