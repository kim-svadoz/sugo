# 기본 하네스 (default)

모든 프로젝트에 언어/프레임워크와 무관하게 항상 적용되는 최소 공통 규칙. 다른 특화 하네스가
감지되지 않았거나 요청한 하네스 id를 찾지 못했을 때 폴백으로도 사용된다.

## 핵심 규칙

1. **작은 커밋, 명확한 메시지.** 하나의 커밋은 하나의 논리적 변경만 담는다.
2. **죽은 코드 금지.** 사용하지 않는 변수·함수·import·주석 처리된 코드는 남기지 않는다.
3. **에러를 삼키지 않는다.** catch/except에서 로그 없이 무시하지 않는다. 의도적으로 무시할 땐 이유를 남긴다.
4. **비밀정보 하드코딩 금지.** API 키·토큰·비밀번호는 코드/커밋에 남기지 않는다.
5. **기존 스타일을 따른다.** 새 파일이 아니면 주변 코드의 네이밍·포맷 관례를 그대로 따른다.
6. **테스트 없는 "완료" 주장 금지.** 동작을 코드로 증명하기 전엔 완료로 보고하지 않는다.

## 체크리스트 (커밋 전)

- [ ] 불필요한 디버그 출력(print/console.log 등) 제거
- [ ] 변경 범위 밖 파일을 건드리지 않았는지 확인
- [ ] 커밋 메시지가 "왜"를 설명하는지 확인
