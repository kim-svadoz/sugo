# JavaScript 하네스 (lang/javascript)

## 핵심 규칙

1. **`var` 금지.** `const`를 기본으로, 재할당이 필요할 때만 `let`.
2. **엄격한 동등비교.** `==`/`!=` 대신 `===`/`!==`.
3. **콜백 지옥 금지.** 비동기는 `async`/`await`로 통일(Promise 체인이 3단 이상이면 리팩토링).
4. **암시적 전역 변수 금지.** 모든 변수는 선언 후 사용.
5. **모듈 경계 명확히.** 순환 참조를 만들지 않는다.
6. **에러 우선 처리.** 콜백 스타일 API를 쓸 때 에러를 항상 먼저 확인한다.

## 체크리스트

- [ ] 새 `var` 선언이 없는지 확인
- [ ] `==`/`!=` 사용이 없는지 확인
- [ ] 미처리 Promise rejection이 없는지 확인
